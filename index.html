9-1 認識類別與物件

什麼是物件導向？

物件導向是一種程式設計方式，將資料與程式碼組合成物件。

  • 物件 Object：資料與程式碼的組合。
  • 屬性 Attribute：描述物件的特質。
  • 方法 Method：定義物件可以執行的動作。
  • 類別 Class：物件的藍圖或樣板。

9-2 使用類別與物件

建立一個 Car 類別

class Car:
    wheels = 4

    def __init__(self, brand, year):
        self.brand = brand
        self.year = year

    def show_info(self):
        print(f"廠牌：{self.brand}，年份：{self.year}")

car1 = Car("Mazda", 2023)
car1.show_info()

重點：class 用來定義類別，__init__() 負責初始化物件。

9-3 繼承

什麼是繼承？

繼承是讓一個類別取得另一個類別的成員，可以提升程式的重複使用性及擴展性。

class Animal:
    def speak(self):
        print("動物發出聲音")

class Dog(Animal):
    def speak(self):
        print("狗狗汪汪叫")

dog = Dog()
dog.speak()
